쓱설치는 APK 파일을 열면 설치할 앱 정보를 바로 보여 주는 한국어 APK 설치 앱입니다.
Shizuku나 무선 디버깅을 연결해 두면, 쓱설치의 [설치] 버튼 한 번으로 보통 몇 초 만에 설치가 끝납니다.

⚡ 빠른 설치 — Shizuku 또는 무선 디버깅
쓱설치의 대표 기능입니다. 둘 중 하나만 연결하면 됩니다.
• 탭 한 번: 쓱설치 화면에서 앱 정보를 확인하고 [설치]를 누르면 끝. 여러 화면을 넘길 필요가 없습니다
• 몇 초면 끝: 설치에 걸린 시간을 초 단위로 보여 드립니다
• 직접 시작: 빠른 설치도 매번 사용자가 [설치]를 눌러야 시작됩니다

[일반 설치] [설치] → Android 설치 화면에서 한 번 더 진행
[빠른 설치] [설치] 한 번 → 보통 몇 초 만에 완료

▸ 방법 1. 무선 디버깅 (Android 11 이상, PC 필요 없음)
• 휴대폰 개발자 옵션에서 '무선 디버깅'을 직접 켭니다
• 페어링은 쓱설치 안에서 진행됩니다
• 무선 디버깅 화면에 나온 6자리 페어링 코드를 쓱설치 알림에 바로 입력하면 연결 끝
• 앱을 오가며 코드를 외울 필요가 없습니다
※ 무선 디버깅은 Wi-Fi에 연결된 상태에서 켤 수 있고, 메뉴 위치는 기기마다 다릅니다.

▸ 방법 2. Shizuku
• Shizuku는 따로 설치하는 별도의 제3자 앱이며, 사용 여부는 선택입니다
• Shizuku를 실행한 뒤 쓱설치의 연결 요청을 허용하면 바로 사용할 수 있습니다
• 이미 Shizuku를 쓰고 있다면 가장 간단한 방법입니다

※ 빠른 설치는 선택 기능입니다. 연결하지 않아도 Android 기본 설치 방식으로 언제든 설치할 수 있습니다.
※ 기기 제조사나 Android 버전에 따라 빠른 설치를 사용할 수 없거나 다르게 동작할 수 있습니다.

■ 원하는 방식으로 설치
• 열기·공유: 파일 관리자, 브라우저, 메신저에서 APK를 열거나 공유 → '쓱설치로 설치'
• 여러 파일: 앱 안에서 APK 여러 개를 골라 연달아 설치
• 링크: 다운로드 링크(URL)를 넣어 바로 설치

■ 설치 전에 한눈에 확인
• 하단 시트에서 아이콘, 앱 이름, 버전, 크기, 분할 파일 수를 먼저 보여 드립니다
• 업데이트 / 낮은 버전 / 오래된 앱 배지로 상태를 바로 파악할 수 있습니다

■ 분할 APK도 그대로
• .apks / .xapk / .apkm 형식 지원

■ 설치가 안 될 때도 친절하게
• 서명 불일치, 저장 공간 부족 등 실패 이유를 알기 쉬운 한국어로 알려 드립니다

■ 기록과 설정
• 최근 설치 기록: 눌러서 바로 앱 열기
• 기본 설치 방식, 테마 설정
• Material You 디자인, 다크 모드 지원

■ 광고 없음, 추적 도구 없음
• 광고도, 추적 도구도 넣지 않았습니다

■ 알아 두세요
• 신뢰할 수 있는 출처에서 받은 APK만 설치하세요.
• Shizuku는 별도 개발자가 만든 제3자 앱입니다.
• 쓱설치는 Google 및 Shizuku와 제휴 관계가 없는 독립 앱입니다.
